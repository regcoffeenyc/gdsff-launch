## Final Page Identity

- Final page name: `GDSFF | Georgian Dynamic Shooting & Functional Fitness Federation`

- Secondary username recommendation: `@gdsff.ge`
- Third-choice username recommendation: `@gdsfforg`
- Primary category recommendation: `Sports Federation`
- Closest fallback categories if the exact option is unavailable: `Sports League`, `Sports Club`, `Nonprofit Organization`
- Recommended CTA button: `Learn More`
- CTA destination: `https://gdsff.org/`
- CTA fallback if `Learn More` is not available: `Contact Us` -> `https://gdsff.org/contact`

## Page Setup Checklist

- Upload the approved logo as the page profile image.
- Use a restrained range-based cover image with the full federation name and slogan.
- Claim the preferred username before publishing any posts.
- Set the category to `Sports Federation` or the closest available professional equivalent.
- Add `https://gdsff.org`, `office@gdsff.org`, and `+995 511 560038` to the contact section.
- Add the short bio and full About text exactly as approved.
- Enable the `Learn More` button and link it to the website homepage.
- Keep page language primary in Georgian, with English support inside key posts.
- Publish the launch announcement first and pin it immediately.
- Follow with Membership, Documents, Leadership, Safety, and Contact posts in that order.
- Turn on Messenger greetings, but route official requests to email.
- Avoid casual reposts, low-resolution imagery, meme-style content, and unverified announcements.
